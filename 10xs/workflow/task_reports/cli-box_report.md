# "Check your own app" box on the board — completion report

Instruction: `10xs/workflow/instructions/20260929_25_site-cli-box.md`

Branch: `feature/cli-box`

## What changed

The owner noted on 2026-09-29 that ready.hireflutter.dev never links the
published `flutter_ready` CLI (https://pub.dev/packages/flutter_ready,
publisher hireflutter.dev). Added three visitor-facing pointers to it,
`site/` only, no grading/data/number changes.

1. **New `site/lib/components/cli_box.dart`** — a quiet, card-styled
   `CliBox` component: heading "Check your own app", one line of intro
   text, a `pubspec.lock`-adjacent code block (`dart pub global activate
   flutter_ready` / `flutter_ready check`, horizontal-scroll-only wrapper
   via `Overflow.only(x: .auto)`, matching `plugin_table.dart`'s
   `.table-scroll` pattern), and two links: "flutter_ready on pub.dev" and
   "Use it in CI (GitHub Action)" → the repo's `#github-action` anchor.
2. **`site/lib/components/headline_panel.dart`** — inserted `const
   CliBox()` between `CountTiles` and the conditional `BlockedList`, so it
   always renders right after the tiles (never pushing them down) and
   above the blocked-plugins list when one is shown.
3. **`site/lib/pages/plugin_page.dart`** — added a `.cli-nudge` line under
   "Version … View on pub.dev": "Check all of your app's plugins at once
   with the flutter_ready CLI →", linking to pub.dev.
4. **`site/lib/components/footer.dart`** — appended "flutter_ready on
   pub.dev" (→ pub.dev/packages/flutter_ready) to the second footer line.
5. **`site/lib/main.server.options.dart`** — regenerated by `jaspr build`
   to register `CliBox.styles`; no manual edit.

No new colours: every colour reused is an existing `theme.dart` token.
